# Autonomous Review Artifacts

Use this directory for sanitized review artifacts that are safe to commit and push.

Expected examples:

- slice schema reviews
- security and privacy reviews
- model-gate reviews
- UI-language reviews
- restore and secrets/logging reviews

Do not place raw health data, provider payloads, tokens, `.env` values, DuckDB files, snapshots, quarantine payloads, or local-only feedback packets here.
